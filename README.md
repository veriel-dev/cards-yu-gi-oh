# Cards Yu-Gi-Oh! - Proyecto de Visualización de Cartas


¡Bienvenido al repositorio de **Fake Cards Yu-Gi-Oh!**! Este proyecto es una aplicación web que permite a los usuarios explorar y visualizar cartas fake del famoso juego de cartas coleccionables Yu-Gi-Oh!. 
La aplicación está diseñada para ser intuitiva y fácil de usar, ofreciendo una experiencia interactiva para los fans del juego.

## Características Principales

**Visualización de Cartas:** Explora una colección de cartas Yu-Gi-Oh! con imágenes detalladas y descripciones.
- **Búsqueda y Filtrado:** Busca cartas por el tipo de carta.
- **Diseño No Responsivo:** Debido a los detalles de las cartas no se han podiro realizar responsive para resoluciones ifneriores a 500px.
- **Interfaz de Usuario Amigable:** Una interfaz limpia y moderna que facilita la navegación y la interacción.

## Instalación

Sigue estos pasos para clonar y ejecutar este proyecto localmente:

1. Clona el repositorio:

   ```bash
   git clone https://github.com/veriel-dev/responsive-web.git
   ```
2. Navega al directorio del proyecto:
 
   ```bash
    cd responsive-web
   ```
3. Instaala las dependencias:

   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```
5. Abre una navegador y visita http://localhost:3000 para ver la aplicación en acción.
